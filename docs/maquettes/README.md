# Maquettes

Les maquettes d'interface du projet, dans leur forme d'origine.

## Comment en déposer une

Glisse le fichier dans ce dossier, puis :

```bash
cd ~/Projets/HERACLES
git add docs/maquettes
git commit -m "Ajouter la maquette <nom>"
git push
```

Les fichiers HTML exportés depuis un outil de conception se déposent tels quels : on ne les
réécrit pas, ils servent de référence. Ce qui en est retenu pour la construction est consigné à
côté, dans un fichier de même nom suffixé `-notes.md`.

## Ce qu'on n'y met pas

Aucune capture ni export contenant de vraies données — noms, adresses, CV. Une maquette se
peuple de personnes inventées.
