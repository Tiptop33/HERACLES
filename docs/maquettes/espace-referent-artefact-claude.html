Reprise Bubble

Un référent ne voit que ses candidats. Pas par filtre d'affichage : c'est la base de données elle-même qui refuse de montrer les autres. Même en modifiant l'adresse dans le navigateur, la fiche d'un candidat qui n'est pas rattaché à lui reste inaccessible — exactement comme on l'a déjà vérifié pour les profils.

Ce qui reste à décider

  • Les listes de choix. « Type de recherche », « Situation », « Clôture », « Appréciation » sont aujourd'hui du texte libre venant de Bubble. En faire de vraies listes évite les fautes de saisie — mais il me faut leurs valeurs exactes.
  • Le taux de remplissage. Utile, ou gadget ? Il indique où le travail reste à faire, mais il peut aussi donner l'impression de noter les référents.
  • L'état du suivi. « Suivi / À contacter / Clôturé » est déduit des champs `cloture` et `archive`. Si tes référents raisonnent avec d'autres étapes, dis-les-moi.
  • Ce qui manque à l'écran ? C'est la question qui compte le plus : qu'est-ce qu'un référent fait tous les jours qu'on ne voit pas ici ?
