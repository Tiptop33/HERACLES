# HERACLES

## Langue

**Toutes les réponses sont rédigées en français.** Cela vaut pour les messages de
discussion, les messages de commit, les descriptions de pull request, les
commentaires du code et la documentation.

## Isolation

HERACLES est **totalement isolé** d'EKOPLAN / MyCollabus : dépôt, nom de stack,
ports, base de données et domaine distincts. Ne jamais réutiliser les volumes, les
ports, les identifiants ni les données d'un autre projet.
